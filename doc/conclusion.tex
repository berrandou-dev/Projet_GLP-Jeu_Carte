\section{Conclusion et perspectives}
\label{sec:conclusion}

\subsection{Résumé du travail réalisé}
\paragraph{} Le projet "Tu n'y peux rien" a été mené à bien dans les délais impartis. Toutes les fonctionnalités demandées dans le cahier des charges ont été implémentées :

\begin{itemize}
\item Jeu complet avec interface graphique Swing
\item 3 niveaux de difficulté pour les bots (Facile, Moyen, Difficile)
\item Détection des combinaisons (simple, double, série, bombe, double joker)
\item Gestion des cartes spéciales (2, Joker)
\item Système de scores et statistiques
\item Tests unitaires (JUnit) couvrant les classes principales
\item Logs détaillés (Log4j)
\end{itemize}

\paragraph{} Au total, ce sont plus de 40 classes Java qui ont été développées, avec une couverture de tests satisfaisante sur les composants critiques.

\subsection{Améliorations possibles du projet}
\paragraph{} Plusieurs extensions pourraient être apportées au projet :

\begin{itemize}
\item \textbf{Mode multijoueur en ligne} : Permettre à plusieurs joueurs humains de jouer à distance via réseau
\item \textbf{Sauvegarde des parties} : Sauvegarder l'état du jeu pour le reprendre plus tard
\item \textbf{Classements et statistiques persistants} : Stocker les scores et victoires dans un fichier ou une base de données
\item \textbf{Animations} : Ajouter des animations lors de la pose des cartes
\item \textbf{Thèmes personnalisables} : Permettre au joueur de changer l'apparence des cartes et du tapis
\item \textbf{Version mobile} : Adapter le jeu pour Android/iOS
\end{itemize}

\paragraph{} Ces améliorations pourraient faire l'objet d'une future version du projet.
